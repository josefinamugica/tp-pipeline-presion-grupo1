
# TP Grupal - Pipeline de Presión Arterial

## Descripción
Este trabajo práctico consiste en desarrollar un programa en Python para procesar datos de pacientes y sus mediciones de presión arterial.

El programa permite leer archivos CSV y JSON, validar los registros, detectar errores y generar reportes con los resultados.

## Herramientas utilizadas
- Python
- Visual Studio Code
- GitHub
